# Inject Scripts

This directory contains scripts for injecting and testing data in the Claryfy backend. These scripts are used for development, testing, and data management purposes.

## Script Categories

### Data Injection
- test-assignments-inject.js - Injects test assignment data
- test-announcements-inject.js - Injects test announcement data
- full-reset-inject.js - Performs a full reset and data injection

### Weaviate Testing
- test-weaviate-assignments.js - Tests Weaviate integration with assignments
- test-weaviate-announcements.js - Tests Weaviate integration with announcements

## Important Notes
- These scripts are for development and testing purposes only
- Do not run these scripts in production
- Some scripts may modify or delete existing data
